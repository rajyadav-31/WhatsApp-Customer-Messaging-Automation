# WhatsApp Automation

## 📌 Project Overview

This project demonstrates WhatsApp automation using Python and PyAutoGUI. It automates user interactions with the WhatsApp interface by controlling the mouse, keyboard, and active application window.

The project was developed as a practical Python automation project to understand GUI automation and automate repetitive WhatsApp-related tasks.

## 🛠️ Technologies Used

* Python
* PyAutoGUI
* Time
* GUI Automation

## ⚙️ Key Features

* Automated mouse and keyboard interactions
* Screen resolution detection
* Active window detection
* Automated interaction with the WhatsApp interface
* Automation of repetitive GUI-based tasks

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/WhatsApp-Automation.git
cd WhatsApp-Automation
```

Install the required package:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

1. Install Python.
2. Install the required dependencies.
3. Open the notebook using Jupyter Notebook or VS Code.
4. Open WhatsApp Web/Desktop as required by the notebook.
5. Run the notebook cells in sequence.
6. Follow the instructions in the notebook.

## ⚠️ Important Notes

This project uses GUI automation through PyAutoGUI. Therefore, screen resolution, window position, and the WhatsApp interface can affect the automation.

Use the automation responsibly and only with accounts, contacts, and messages that you are authorized to interact with.
